# Admin maintenance and modification

Superusers have read-only rollback metadata and a searchable feature-to-file guide. Guides do not execute scripts, edit source or download private backups. Only approved metadata/paths are displayed; secrets and archive contents are not served.

A fresh installation has no historical snapshots. Record its own version-matched private procedures before deployment. For modifications use [the component map](COMPONENT-MAP.md). No original installation history, task definitions or backup paths are shipped in this repository.
