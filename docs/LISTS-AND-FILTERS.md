# Lists, filters and refresh

Use search/date filters, row-size controls and pagination to find allottees, bills and payments. The Allottees list can sort by last billed month and open an allottee's bills. Refresh reloads the current section; errors retain a visible retry path.

Unsaved edits and uncertain writes need review before retrying. No financial write is automatically repeated merely because a response was lost.

## Distinguishing multiple allotments

Add or edit an allottee and enter the optional **Allotment description**, for example Shop 12, Market Block. The app and Admin show **Name — description** in lists and selection menus, including bills, payments and email drafts. Search can find the description. Existing records start blank; names, IDs and financial records are unchanged. The invoice/report name remains the name field; use the separate allotment-description placeholder when wanted in email templates. Description is included in private business exports and backups; older exports without it import as blank.
