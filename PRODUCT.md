# BillTrack

A configurable local/office billing application using Django, React, SQLite and Waitress. Users manage allottees, invoices, receipt dates, collections, penalties and reports. Financial calculations and validation are retained. Organisation identity, signing authority, tax registration, bank/payee details and logos are private installation data, never source defaults.

Preserve the BillTrack application identity, keyboard accessibility, readable errors and printable invoice layouts. Configuration uses Admin and local SQLite/media; runtime credentials use .env. This repository supports new installations and is initially private. Existing installations require a separately planned migration.
